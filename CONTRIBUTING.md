# Contributing

1. Create a focused branch from `main`.
2. Run `bun install --frozen-lockfile`, `bun run build`, `bun run test`, and
   the Rust format, clippy, and test commands before opening a pull request.
3. Add or update tests for behavior changes. Keep provider credentials and
   generated assets out of commits.
4. Explain migrations, compatibility impact, and user-facing changes in the
   pull request description.

Contributions are accepted under the Apache-2.0 license. By submitting a
contribution, you agree that it may be distributed under that license.
